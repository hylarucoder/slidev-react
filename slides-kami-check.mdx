## 内核很小，周边很复杂

循环本身很小。真正让它在功能增长时保持稳定的，是**围绕它的基础设施**。

1. 一个能跑的 Agent 循环大约 20 行代码。
2. 控制流住在工具里，而不是分支丛生的内部状态。
3. Workflow 与 Agent 的差别：代码里预定义路径，还是模型在运行时挑路径。

> 如果你的循环每个迭代都在变长，你修的是错的那一层。税是在循环*外面*付的。
