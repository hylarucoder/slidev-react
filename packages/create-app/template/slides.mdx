# My Slidev React Deck

这是一份起手式。先翻一下，再把内容换成你自己的。

---

## 写流程图

<div id="mermaid-smoke">
  <MermaidDiagram>{`graph LR
  Deck[Slides]
  Deck --> Charts
  Deck --> Mermaid
  Charts --> Presenter
  Mermaid --> Export
  `}</MermaidDiagram>
</div>

架构图、流程图、决策树——mermaid 都能画。
